feat(b2c): add customer-behavior module + theme-aware charts

Extends the existing B2B planner app with a B2C ("Flavor A") lens
that reasons about individual shoppers alongside stores. All new
work is additive — the existing B2B pages, routes, and pipeline
are untouched.

Backend
-------
- config.py: B2C path helpers + reference date/valid-timestamp
  constants, isolated from the B2B pipeline.
- pipeline/b2c_01..b2c_05: five-stage B2C pipeline
    01 customer features (RFM-style + behavior counts)
    02 KMeans clustering into 5 personas
    03 pv -> cart -> fav -> buy funnel metrics
    04 frequently-bought-together bundles (association rules)
    05 per-user next-best-offer recommendations
- scripts/sample_user_behavior.py: DuckDB-based user-preserving
  sampler that turns the 3.4 GB UserBehavior.csv into a
  manageable 50k-user slice.
- scripts/run_b2c_pipeline.py: orchestrator that runs all five
  steps end-to-end and writes CSVs to outputs/b2c/.
- api/b2c_routes.py: seven FastAPI endpoints under /api/b2c/*
  (summary, customers, customer detail, segments, segment detail,
  funnel, bundles) with typed Pydantic responses.
- api/main.py: wires the new b2c_router.
- ai/chat_tools.py: five new Gemini function-calling tools so the
  assistant can answer B2C questions (customer profile, segments,
  segment detail, funnel summary, top bundles).
- scripts/smoke_test_b2c_api.py: in-process TestClient smoke test.

Frontend
--------
- api.ts: seven typed fetchers + eight TypeScript models for the
  B2C endpoints.
- components/Layout.tsx: sidebar restructured into three groups
  (Stores B2B / Customers B2C / Tools).
- pages/CustomersPage.tsx: paginated customer list with segment,
  min-buys, sort, and user-ID search filters.
- pages/CustomerDetailPage.tsx: Customer-360 view (persona,
  personal funnel, behavioral features, top recommendations).
- pages/CustomerSegmentsPage.tsx: segment cards + distribution
  chart + detail panel (avg behavior, top items, sample users).
- pages/FunnelPage.tsx: overall funnel KPIs, daily trend, and top
  categories by view-through.
- components/CustomerKpiStrip.tsx: compact B2C KPI row injected
  into the existing Dashboard.
- App.tsx: four new B2C routes wired.

Chart theme fixes
-----------------
- components/analytics/chartTheme.ts: tooltip contentStyle,
  labelStyle, and itemStyle now use `rgb(var(--color-...))`
  design tokens so tooltips flip cleanly between light and dark
  themes. `cursor: false` removes the default Recharts hover
  shadow across every chart.
- index.css: global Recharts overrides — theme-aware axis lines,
  tick labels, grid lines, legend text, and polar/radar chrome.
  Uses !important on the Recharts class hooks so it wins over
  inline SVG stroke/fill attributes without touching individual
  chart files. Also adds formatCompactNumber util for compact
  Y-axis ticks.

Data & docs
-----------
- B2C_PROPOSAL.md/.docx/.pdf: one-page layman proposal describing
  scope, dataset, new pages, and risks.
- .gitignore: exclude backend/data/raw/*.zip, *.gif, and other
  large binaries so the repo stays lean.
